# Поиск компании на мероприятия

Приложение помогает находить людей для совместного отдыха: прогулок, концертов, выставок, настольных игр и других мероприятий. Каждый пользователь может создать своё событие или присоединиться к существующему, познакомиться с участниками и договориться о встрече.

## Как это работает

События представлены карточками с названием, фотографией, датой, местом и стоимостью участия. На карточке видно количество участников и максимальный размер компании, например `3/7 👤`. Для бесплатных событий отображается отметка «Бесплатно».

Организатор выбирает один из двух способов вступления:

- **Свободное вступление:** пользователь присоединяется сразу, если есть свободное место.
- **По заявке:** пользователь отправляет заявку и становится участником после подтверждения организатором.

Из списка участников можно открыть профиль человека и написать ему в личные сообщения, чтобы познакомиться и обсудить детали встречи.

## Планируемые возможности

- Регистрация и личный профиль с фотографией и описанием.
- Поиск событий и фильтры по городу, дате, категории и стоимости.
- Создание, редактирование и отмена своих событий.
- Вступление в события, обработка заявок и выход из состава участников.
- Личные переписки между пользователями.
- Раздел со своими событиями, участием и отправленными заявками.

## Технологии

Планируемый стек:

- **Сервер:** Kotlin + Ktor, архитектура модульного монолита.
- **База данных:** PostgreSQL.
- **Клиент:** устанавливаемое приложение на Compose Multiplatform.
- **Запуск сервера:** Docker Compose.
