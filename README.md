# TaskQuest

**TaskQuest**: приложение для управления повседневными задачами с элементами RPG. Пользователь планирует учёбу, работу и личные дела, а выполнение этих задач помогает развивать персонажа и продвигаться в игре.

## Зачем нужен проект

Помогает помнить о задачах и, самое главное, делает их выполнение интереснее. TaskQuest добавляет к планированию долгосрочную игровую цель: результат реальной работы превращается в ресурсы для развития персонажа и новых игровых испытаний

## Как это работает

Пользователь создаёт задачи, при необходимости делит их на подзадачи и проводит focus-сессии. За выполненные задачи и завершённые сессии он получает опыт и игровые ресурсы. Они помогают развивать персонажа, получать экипировку и проходить игровые испытания: сражения, подземелья и боссов.

Планируемый основной цикл:

```text
Реальная задача → выполнение → награда → развитие персонажа → игровое испытание
```
